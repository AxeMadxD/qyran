What this browser is actually keeping

One key, qyran:data, holding one JSON object: the keeper accounts, which one is logged in, and a list of follows and saved plans for each. The light or dark choice is a second, tiny key, qyran:mode, because it has to be read before the page is painted.

If you clear it

Browser settings, DevTools or the buttons on this page all remove the same data. There is no copy on a server, so the pages simply go back to their empty state — which is how they look for every first-time visitor.
